사용 순서
  1. ① 시나리오: 표적의 마지막 위치(LKP)와 무인기 출발점, 표적이 움직이는 방식을 정합니다. 지도 위 점들이 표적 후보(particle)입니다.
  2. ② 탐색 계획: SAROPS가 최대로 할 점수와 조건을 고르고 탐색 계획 실행을 누릅니다.
  3. ③ 실행 목록: 끝난 실행을 골라 엽니다. 필터로 시험 종류·방법·조건별로 볼 수 있습니다.
  4. ④ 결과: 점수를 보고, 아래 재생 막대로 비행을 다시 봅니다(← → 1초, Shift 1분, 스페이스 재생).
