- [x] 1.1 탐색영역 항을 신규 탐색 면적 또는 미탐색 영역 감소량 등으로 정의한다.
- [ ] 1.2 신규 탐색 면적의 계산 해상도와 센서 footprint 반영 방식을 정한다.
- [x] 1.3 반복 관측과 시간 경과 후 재탐색의 취급을 정한다.
- [x] 1.4 POS 항을 스텝별 발견 확률 증가량으로 사용할지 확정한다.
- [x] 1.5 면적과 확률의 단위·크기 차이를 정규화한다.
- [ ] 1.6 두 항을 결합하는 수식과 가중치의 의미를 정의한다.
- [ ] 1.7 최종 성과와 조기 발견 중 시간 선호 및 할인 방식을 정한다.
- [x] 1.8 에너지 제약과 예산 소진 시 처리 방식을 명시한다.
- [ ] 1.9 결합 점수 외에 탐색 면적과 POS도 별도 평가 지표로 정의한다.

완료 기준: 각 보상 항의 의미·단위·수식·가중치가 명시되어 있다.
